# Worbee — Workspace Builder: Delivery Tasks

## Project setup

- [ ] Create a Next.js application with TypeScript and Tailwind CSS.
- [ ] Establish the Monis-inspired visual system: warm Bali palette, red accent, typography, spacing, and responsive layout.
- [ ] Configure the GitHub repository and add `desent-bot` as a collaborator.
- [ ] Connect the repository to Vercel and prepare environment variables for the enquiry endpoint.

## Product data

- [ ] Define rental products, images, descriptions, and monthly prices in a reusable data model.
- [ ] Add at least two desk choices: compact desk and wide or standing desk.
- [ ] Add at least two chair choices: ergonomic task chair and premium or lounging chair.
- [ ] Add accessories: monitor, desk lamp, plant, keyboard/mouse kit, and storage.
- [ ] Support quantities for applicable accessories, including one or two monitors.

## Workspace builder

- [ ] Build the full-screen visual workspace preview.
- [ ] Render the selected desk and chair in the preview.
- [ ] Render accessories in natural positions within the scene.
- [ ] Add visual transitions when furniture or accessories change.
- [ ] Build category controls with product cards, prices, selected states, and short descriptions.
- [ ] Add reset and “Surprise me” actions.
- [ ] Keep the configuration state synchronized across the preview, controls, and summary.

## Summary and enquiry

- [ ] Build a persistent summary with selected items, quantities, item count, and estimated monthly price.
- [ ] Create the expanded checkout/enquiry view with an itemized setup summary.
- [ ] Collect name, email or WhatsApp, delivery date, rental duration, Bali location, and optional notes.
- [ ] Send the enquiry to the selected backend, email service, or form provider.
- [ ] Show a clear confirmation state after successful submission.

## Quality and launch

- [ ] Ensure the builder is responsive on desktop, tablet, and mobile.
- [ ] Add keyboard support, visible focus states, and accessible labels for every visual control.
- [ ] Optimize image assets and validate a fast initial page load.
- [ ] Test the core configuration flow, price calculation, reset action, and enquiry submission.
- [ ] Deploy the application to Vercel.
- [ ] Verify the public URL, GitHub repository access, and production enquiry flow.
